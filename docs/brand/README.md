# Material da marca

- `logo-original.png`: foto de perfil do Instagram (240px), usada só como referência.
- `logo-src-003.png`: recorte em alta do logo tirado da arte de inauguração. É a fonte do vetor.
- `trace_logo.py`: vetoriza o logo por camadas de cor com potrace. Gera `.shots/logo-traced.svg`, copiado para `public/logo.svg`.
- `logo_parts.py`: extrai montanhas, sol, fita e risco em `src/components/LogoParts.tsx`.
- `instagram/`: fotos do perfil selecionadas.
- `videos/` (ignorado no git): reels baixados com `yt-dlp`. Os loops usados no site estão em `public/videos`, cortados para remover legendas e comprimidos.

Reels usados: DbLuhk4hMyB (calda, hero), DGoUwITvppM (vitrine, self-service), Da8tNeKhKLa (marmitinha), Da6PqzWNOIF (colher, Petrópolis).
