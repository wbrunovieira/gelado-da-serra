# Gelado da Serra

Projeto Next.js (App Router) com TypeScript e Tailwind CSS.

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript
- pnpm

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

Abra http://localhost:3000.

## Scripts

- `pnpm dev` — servidor de desenvolvimento
- `pnpm build` — build de produção
- `pnpm start` — roda o build
- `pnpm lint` — lint
